# Leanlet 0.3.0-beta.6

This release updates the npm package presentation to match Leanlet's current
framework surface. It does not change runtime behavior from 0.3.0-beta.5.

## Documentation

- Describes standalone Leanlets and managed orchestration as complementary
  adoption paths.
- Summarizes kernel scheduling, lifecycle, policy, resource budgets, typed
  flows, application checks, model packs, capability routing, explicit
  fallback, asset planning, and evaluation.
- Uses the `beta` install channel consistently while retaining `next` as an
  equivalent prerelease channel.

## Compatibility

The release is documentation-only apart from package version metadata. No API
or behavioral migration is required from 0.3.0-beta.5.
