# Leanlet 0.3.0-beta.3

This release removes the vision runtime from the default install path for kernel-only and custom-adapter applications.

```bash
npm install leanlet-ai@0.3.0-beta.3 --save-exact
```

Import orchestration from `leanlet-ai/kernel`. No model backend is installed for this path. To use the built-in vision adapter, install `@huggingface/transformers` explicitly beside Leanlet.

The change is package-level and backward compatible at the JavaScript API boundary. Existing installations that already declare the transformer runtime continue to work. Fresh vision consumers must add the optional peer.
