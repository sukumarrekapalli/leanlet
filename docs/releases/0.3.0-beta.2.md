# Leanlet 0.3.0-beta.2 release notes

## Kernel-only browser entry

This release adds `leanlet-ai/kernel`, a focused package entry for applications that use the Leanlet kernel, flows, and scoped Leanlets without the vision runtime.

```ts
import {
  accepted,
  createLeanletKernel,
  defineFlow,
} from 'leanlet-ai/kernel';
```

The root `leanlet-ai` entry remains backward compatible. Applications that do not use `VisionLeanlet` should prefer the kernel entry so bundlers do not emit vision worker and ONNX runtime assets that the application cannot reach.

This change was driven and verified by the Leanlet Writer reference application. Its production build no longer emits the unused 21 MB ONNX WebAssembly asset.

## Compatibility

- No existing root exports were removed or changed.
- The new subpath contains the kernel, flow, and scoped-Leanlet APIs and their public types.
- npm tag: `next`.
