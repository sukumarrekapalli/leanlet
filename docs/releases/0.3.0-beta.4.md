# 0.3.0-beta.4 release candidate

This candidate adds public contracts for application-supplied model packs and
kernel-delegated checks.

## Added

- `defineModelPack()` for immutable model identity, revision, license, provider,
  asset, context, quantization, and resident-memory metadata.
- `defineModelLeanlet()` for connecting an application runtime adapter to the
  managed kernel lifecycle.
- `defineCheck()` and `runCheck()` for typed product checks routed to registered
  Leanlets with explicit pass/review/fail decisions.
- Tests covering custom-model lifecycle, provider selection, provenance,
  validation, check routing, and preserved abstention.

## Compatibility

These APIs are additive. The 0.2 `defineLeanlet()` and `VisionLeanlet` APIs are
unchanged. Existing 0.3 kernel definitions and flows require no migration.

## Limits

Leanlet records declarations and manages execution; it does not sandbox custom
JavaScript, verify a model's quality, or make a check threshold valid. Model
authors remain responsible for runtime integration, licenses, representative
evaluation, uncertainty policy, and user-facing review behavior.
